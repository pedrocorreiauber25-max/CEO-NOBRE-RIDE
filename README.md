# Nobre Digital

**Tecnologia. Estratégia. Crescimento.**

Website institucional da Nobre Digital — marca dedicada à criação de websites, aplicações e sistemas digitais para pequenos negócios.

## Estrutura inicial

- `index.html` — website institucional responsivo, em português de Portugal.
- Identidade visual — preto e dourado, premium.
- Serviços — websites, aplicações/sistemas de gestão e automação.
- Produto próprio em validação — Nobre Manager.

## Publicação

O projeto está preparado para GitHub Pages. No repositório, abrir **Settings → Pages** e selecionar **Deploy from a branch → main → /(root)**. Guardar e aguardar a publicação.

URL prevista: https://pedrocorreiauber25-max.github.io/CEO-NOBRE-RIDE/

## Antes do lançamento comercial

1. Definir email e telefone/WhatsApp oficiais.
2. Substituir o formulário provisório por um canal de contacto funcional.
3. Adicionar portefólio com projetos reais e autorização dos clientes.
4. Definir preços, condições, política de privacidade e termos.
5. Testar em telemóveis e computadores.

## Princípios

- Começar com ferramentas gratuitas e custos controlados.
- Não apresentar projetos em desenvolvimento como produtos já disponíveis.
- Validar procura e conseguir clientes antes de assumir despesas recorrentes.
