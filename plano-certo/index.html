Como calculamos a meta

As despesas regulares são convertidas para um equivalente semanal. Aos valores somam-se 200 € por semana para compras de casa. Para cada dívida, calculamos uma contribuição que procura liquidar o saldo em 156 semanas, respeitando a prestação mínima que introduziste. Juros futuros ou encargos que não estejam registados podem alterar o resultado.

Definições

Personaliza o plano e protege os teus dados.

Compras para casa

Por defeito são 200 € todas as semanas. Podes alterar este valor quando quiseres.

Lembretes

A aplicação mostra os pagamentos do dia sempre que a abres. Podes também autorizar notificações enquanto a aplicação estiver aberta. O navegador pode limitar notificações quando a aplicação está fechada; para alertas garantidos em segundo plano é necessário um serviço de notificações.

Cópia de segurança

Exporta os teus dados para um ficheiro e guarda-o num local seguro. A aplicação não envia as tuas dívidas para o GitHub.

Privacidade

Os dados ficam guardados neste navegador/dispositivo. Limpar os dados do navegador ou trocar de dispositivo sem importar uma cópia pode apagar o registo local. Não introduzas palavras-passe, números completos de cartões ou credenciais bancárias.
